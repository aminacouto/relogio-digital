# Relógio Digital Inteligente (PWA)

Aplicação web interativa de relógio digital desenvolvida com **HTML, CSS e JavaScript puro**, estruturada como uma **Progressive Web App (PWA)** instalável.  
O projeto foi criado com foco em experiência do usuário, personalização visual e exploração de Web APIs modernas sem utilização de frameworks.

## ✨ Funcionalidades

- ⏰ Exibição de horário em tempo real (12h ou 24h)
- 📅 Data completa com dia da semana
- 🎨 Personalização de cor e tema (claro, escuro e automático)
- 🌗 Tema automático baseado no horário do dia
- 🎯 Modo foco em tela cheia (fullscreen)
- 🖱️ Arrastar e redimensionar o relógio no modo foco
- 💾 Salvamento automático de preferências com LocalStorage
- 🌦️ Exibição de clima atual via geolocalização (Open-Meteo API)
- 📱 Instalável como aplicativo (PWA)

## 🧠 Conceitos aplicados

- Manipulação avançada do DOM
- Persistência de estado no navegador
- Web APIs (Fullscreen, Geolocation, Fetch API)
- Sincronização precisa de tempo com `setTimeout`
- Animações CSS para transições suaves
- Design responsivo e interface glassmorphism
- Arquitetura front-end sem frameworks

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Progressive Web App (PWA)
- LocalStorage
- Open-Meteo API

## 🎯 Objetivo do projeto

Explorar recursos modernos da plataforma web e desenvolver uma aplicação leve, personalizável e instalável, simulando a experiência de um aplicativo desktop diretamente no navegador.

---

⭐ Projeto desenvolvido como parte da evolução prática em desenvolvimento Front-End, com foco em performance, usabilidade e uso direto das APIs nativas da Web.
